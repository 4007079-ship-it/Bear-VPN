## Что нового

- **Android, режим VPN: исправлена работа через Wi‑Fi.** DNS телефона теперь идёт через сервер, как в Hiddify. Раньше запросы адресов сайтов уходили к роутеру и провайдеру мимо туннеля, и через Wi‑Fi сайты не открывались.

## Первый запуск на macOS

Программа не подписана сертификатом Apple, поэтому при первом запуске macOS её заблокирует:
- **macOS 15 и новее:** «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
- **macOS 13–14:** правый клик по Bear VPN в «Программах» → «Открыть» → «Открыть».

## Известные ограничения

- Режим VPN (весь трафик) есть на Android, Windows и macOS. На Linux пока нет.
- Версии для iPhone пока нет: для неё нужен платный аккаунт разработчика Apple.
- AmneziaWG, WireGuard, TUIC и HTTP-прокси пока только импортируются.
- Windows SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае».
