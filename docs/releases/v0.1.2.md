Bear VPN для Android и Windows.

## Скачать

| Система | Файл |
|---|---|
| **Windows 10/11 (64 бит)** — установщик | `Bear-VPN-0.1.2-windows-setup.exe` |
| Windows без установки | `Bear-VPN-0.1.2-windows-x64.zip` — распакуйте целиком, запустите `BearVPN.exe` |
| **Android 6.0+** | `Bear-VPN-0.1.2-android.apk` |

Файлы без номера версии (`Bear-VPN-android.apk` и др.) — те же самые, для постоянных ссылок «последняя версия».
`SHA256SUMS.txt` — контрольные суммы.

## Что нового

- **IP-адрес на главной:** сервер из ключа и реальный IP выхода, который видят сайты, — с флагом, городом и провайдером.
- **IPv6:** переключатель «IPv6 через VPN» и выбор, по IPv4 или IPv6 подключаться к серверу.
- **Hysteria2 с маскировкой salamander** теперь подключается.
- **Отпечаток сертификата `pcs=`** в ссылках сохраняется — нужен для серверов с самоподписанным сертификатом.
- **fragment** переведён на новый механизм ядра Xray 26 (finalmask).
- Предупреждение при добавлении ключа с `insecure=1`: ядро Xray 26 его больше не поддерживает, нужен `pcs=`.
- Каждое изменение проверяется автоматически на тестовых серверах: VLESS Reality (TCP, XHTTP), VLESS/VMess WS+TLS, Trojan, Shadowsocks, Hysteria2, все настройки обхода блокировок и несколько серверов сразу.

## Известные ограничения

- AmneziaWG, WireGuard, TUIC и HTTP-прокси пока только импортируются, подключение к ним появится позже.
- Режим VPN на Windows требует прав администратора.
- Программа не подписана: Windows SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае».
