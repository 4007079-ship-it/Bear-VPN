Первая тестовая версия Bear VPN для Android и Windows.

## Скачать

- **Android 6.0+** — `Bear-VPN-0.1.0-android.apk`. При установке разрешите установку из этого источника.
- **Windows 10/11 (64 бит)** — `Bear-VPN-0.1.0-windows-x64.zip`. Распакуйте архив целиком и запустите `BearVPN.exe`; папка `xray` должна лежать рядом.
- `SHA256SUMS.txt` — контрольные суммы файлов.

## Что умеет

- Добавление серверов: ссылки vless, vmess, trojan, ss, hysteria2 и др., ключи `vpn://`, конфиги sing-box / Clash / Xray, QR-коды (камера, картинка), файлы.
- Подписки по ссылке: автообновление, трафик и срок действия.
- Режимы: «Прокси», «Системный прокси» (Windows), «VPN».
- Возврат настроек прокси Windows при отключении и закрытии, значок в трее, скорость и трафик.
- Настройки обхода блокировок (по умолчанию выключены): fragment, xmux, несколько серверов сразу.

## Известные ограничения

- AmneziaWG, WireGuard, TUIC и HTTP-прокси пока только импортируются, подключение к ним появится позже.
- Режим VPN на Windows требует прав администратора и пока экспериментальный.
- Сборка не подписана: Windows SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае».
